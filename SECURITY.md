# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `main` | Yes |

## Reporting a Vulnerability

Please do not report security problems in public issues, discussions, or pull requests.
Report them privately: <https://github.com/rohanhong/AquaSOT/security/advisories/new>.
Include the affected component and version, steps to reproduce, the impact, and a suggested fix if you have one.

## What to Expect

- An acknowledgement within 7 days.
- Updates as the report is triaged and fixed.
- Coordinated disclosure once a fix is released, with credit unless you prefer otherwise.

## Scope

In scope: the code in this repository (model, training, evaluation, and preprocessing scripts). Out of scope: third-party dependencies such as PyTorch, timm, and OpenCV, which should be reported upstream.
