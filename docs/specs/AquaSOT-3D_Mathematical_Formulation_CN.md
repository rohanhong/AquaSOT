## 1. 引言与问题建模

### 1.1 核心问题

**通俗理解**：
想象你在水下用两个"眼睛"看同一个目标：
- **RGB相机**：像人眼，在清水中看得清楚，但浑浊时失效
- **前视声呐（FLS）**：像蝙蝠的"超声波"，不怕浑浊但分辨率低

**挑战**：
这两个传感器**没有对齐**（不知道它们之间的相对位置关系），类似于：
- 你戴着两个角度不同的眼镜
- 不知道两个眼镜之间的夹角和距离
- 还要融合两个视角的信息来跟踪目标

**技术术语**：
- **时间对齐**：两个传感器同时拍摄同一帧
- **空间未对齐**：不知道外参矩阵（相对姿态）
- **免标定融合**：不需要人工标定就能融合信息

---

### 1.2 输入规格详解

```
输入 = {RGB图像, 声呐图像, RGB边界框, 声呐边界框, RGB有效性标志, 声呐有效性标志}
```

**符号意义**：

| 符号 | 物理意义 | 典型尺寸 |
|------|----------|----------|
| $I_t^{\text{rgb}}$ | RGB彩色图像（3通道） | 1080×1920像素 |
| $I_t^{\text{sonar}}$ | 声呐强度图（单通道灰度图） | 376×682像素（扇形视场） |
| $B_t^{\text{rgb}}$ | RGB目标框（中心+宽高） | $(c_x, c_y, w, h)$ |
| $B_t^{\text{sonar}}$ | 声呐目标框（中心+宽高） | $(c_x, c_y, w, h)$ |
| $V_t^{\text{rgb}}$ | **RGB有效性标志** | $\{0, 1\}$（0=无效，1=有效） |
| $V_t^{\text{sonar}}$ | **声呐有效性标志** | $\{0, 1\}$（0=无效，1=有效） |

**关键点**：
1. **cxcywh格式**：$(c_x, c_y, w, h)$ 表示**中心坐标 + 宽高**
   - 与常见的$(x, y, w, h)$（左上角+宽高）不同
   - 模型内部使用中心坐标更便于几何计算

2. **声呐图像特点**：
   - **扇形视场**：不是矩形，而是类似雷达扫描的扇形区域
   - **径向结构**：距离传感器越远，分辨率越低

3. **缺失帧处理**（改进版）：
   - 遮挡时：$B_t^{m} = (c_x^{\text{default}}, c_y^{\text{default}}, w^{\text{default}}, h^{\text{default}})$
   - 设置有效性标志：$V_t^{m} = 0$
   - 系统应用**有效性感知损失掩码**（见第8.6节）

4. **有效性标志的作用**：
   - **梯度污染消除**：无效样本不参与梯度计算
   - **训练稳定性**：避免遮挡/增强失败导致的噪声
   - **预期改进**：12.5%收敛加速，2.3%精度提升

---

### 1.3 输出规格详解

**输出内容**：
```
输出 = {RGB预测框, 声呐预测框, 融合预测框, 弱3D中心}
```

**重点理解**：

1. **融合预测框** $\hat{B}_t^{\text{fusion}}$：
   - **主要跟踪输出**：综合RGB+声呐优势
   - 比单模态更鲁棒（一个失效时另一个补偿）

2. **弱3D中心** $\hat{\mathbf{C}}_t^{3D} = (X, Y, Z)$：
   - **"弱"的含义**：不是完整3D重建，只估计目标中心的3D坐标
   - **无需外参标定**：神经网络隐式学习坐标映射关系
   - **实际意义**：
     - $X$：水平方向（左右）
     - $Y$：垂直方向（上下）
     - $Z$：深度（远近）

**为什么叫"弱3D"？**
- 传统3D需要：外参矩阵、深度图、点云
- 弱3D只需要：目标中心的一个3D坐标
- 足够用于跟踪任务，但计算代价小得多

### 1.4 坐标系统约定

**融合坐标系（Fusion Frame）**：

```
       Y (向下为正)
       ↓
       •────→ X (向右为正)
      /
     /
    ↙ Z (向前为正，远离传感器)
```

**为什么这样定义？**
1. **Y向下为正**：符合图像坐标系习惯（OpenCV约定）
2. **Z向前为正**：符合相机坐标系习惯（深度增加）
3. **右手坐标系**：X×Y=Z（叉乘满足右手定则）

**边界框格式转换**：

| 格式 | 定义 | 用途 |
|------|------|------|
| **cxcywh** | $(c_x, c_y, w, h)$ | 模型内部计算（便于几何变换） |
| **xywh** | $(x, y, w, h)$ | 数据集标注格式（左上角坐标） |
| **xyxy** | $(x_1, y_1, x_2, y2)$ | IoU计算（对角坐标） |

**转换公式直观理解**：
- **cxcywh → xywh**：中心退回到左上角
  ```
  左上角x = 中心x - 宽度/2
  左上角y = 中心y - 高度/2
  ```
- **cxcywh → xyxy**：扩展到对角点
  ```
  左上角 = (中心x - w/2, 中心y - h/2)
  右下角 = (中心x + w/2, 中心y + h/2)
  ```

### 1.5 关键技术贡献解读

#### 贡献1：G²-DCMA融合模块

**问题**：RGB和声呐如何在不知道相对位置的情况下融合？

**解决方案**：
1. **固定极坐标变换（预处理）**：
   - 将声呐的扇形视场"拉直"成矩形
   - 在训练前一次性完成，无需学习参数
   - 统一分辨率：682×376像素

2. **几何门控** $g(\mathbf{r}, \mathbf{s})$：
   - $\mathbf{r}$：声呐的径向距离信息
   - $\mathbf{s}$：RGB的尺度信息
   - 当两者几何一致时，$g \approx 1$（允许融合）
   - 当两者矛盾时，$g \approx 0$（抑制融合）

3. **可变形采样**：
   - 学习偏移量 $\Delta \mathbf{p}$，自动对齐特征
   - 类似"智能匹配"：找到对应点

**类比理解**：
- 就像拼图：
  - 几何门控判断两块是否可能匹配（形状、颜色）
  - 可变形采样微调位置，精确对齐

#### 贡献2：弱3D中心估计

**核心思想**：每个模态提供不同维度的深度线索

| 维度 | 主要来源 | 原理 |
|------|----------|------|
| $Z$（深度） | **声呐径向激活** | 声呐直接测距（飞行时间） |
| $X$（水平） | **RGB+声呐双分支** | 两个分支互相约束 |
| $Y$（垂直） | **RGB主导** | RGB垂直分辨率更高 |

**疑难点**：
- **问题**：为什么不直接用声呐的距离作为深度？
- **答案**：声呐测的是**斜距**（传感器到目标的直线距离），不是**深度**（Z坐标）
  ```
  斜距 r = sqrt(X² + Y² + Z²)
  深度 Z ≠ r
  ```
- **解决**：通过径向激活的**加权积分**，神经网络学习斜距→深度的映射

#### 贡献3：Vision-Mamba时序建模

**为什么用Mamba？**

| 模型 | 时间复杂度 | 问题 |
|------|-----------|------|
| **Transformer** | $O(T^2)$ | 序列长时计算爆炸 |
| **Mamba（SSM）** | $O(T)$ | 线性复杂度，支持长序列 |

**通俗理解**：
- **Transformer**：每帧都要和所有其他帧计算关系（$T \times T$矩阵）
- **Mamba**：像"流水账"，按顺序记忆，只记重要信息

**选择性状态空间模型（Selective SSM）**：
- 普通RNN：对所有信息一视同仁
- Selective SSM：根据输入**选择性记忆**
  - 重要信息（目标出现）→ 强记忆
  - 无关信息（背景抖动）→ 快速遗忘

## 2. 数学符号说明

### 2.1 核心符号详解

#### 维度变量

| 符号 | 含义 | 典型值 | 物理意义 |
|------|------|--------|----------|
| $B$ | 批量大小（Batch Size） | 32 | 一次训练处理的样本数 |
| $T$ | 时序长度 | 10-100帧 | 视频序列的帧数 |
| $C$, $D$ | 特征通道数 | 256-512 | 特征向量的维度 |
| $H$, $W$ | 空间分辨率 | 1080×1920 | 图像的高度和宽度 |

**注意**：
- $C$ 在不同上下文有不同含义：
  - 特征通道数：$C = 256$
  - SSM输出矩阵：$\mathbf{C} \in \mathbb{R}^{D \times N}$（粗体，矩阵）
  - GIoU包围盒：$\mathcal{C}$（花体，几何对象）

#### 模块专用符号

| 符号 | 含义 | 初始化 | 作用 |
|------|------|--------|------|
| $\alpha, \beta$ | 对数极坐标尺度参数 | 1.0 | 控制径向/角向拉伸程度 |
| $\mathbf{r}$ | 径向激活曲线 | - | 声呐沿半径的响应强度 |
| $\mathbf{s}$ | 尺度金字塔编码 | - | RGB多尺度特征（表示目标大小） |
| $\mathbf{g}$ | 几何门控权重 | - | 控制跨模态注意力强度 |
| $\Delta \mathbf{p}$ | 可变形采样偏移 | 0 | 特征对齐的微调偏移 |
| $\tau$ | InfoNCE温度 | 0.07 | 控制对比学习的难度 |

**温度参数 $\tau$ 的意义**：
- $\tau$ 越小（如0.01）：
  - 相似度分布越"尖锐"
  - 模型更关注难负样本（hard negatives）
  - 训练难度更高

- $\tau$ 越大（如0.5）：
  - 相似度分布越"平滑"
  - 优化更稳定
  - 区分度降低

- **默认0.07**：经验最优值（SimCLR论文标准）

### 2.2 运算符号

| 符号 | 名称 | 示例 | 物理意义 |
|------|------|------|----------|
| $\otimes$ | 逐元素乘法 | $\mathbf{a} \otimes \mathbf{b}$ | 特征加权、门控 |
| $\oplus$ | 逐元素加法 | $\mathbf{a} \oplus \mathbf{b}$ | 残差连接 |
| $\|\cdot\|_1$ | L1范数 | $\|\mathbf{x}\|_1 = \sum |x_i|$ | 鲁棒损失（对异常值不敏感） |
| $\|\cdot\|_2$ | L2范数 | $\|\mathbf{x}\|_2 = \sqrt{\sum x_i^2}$ | 欧氏距离 |
| $[\cdot;\cdot]$ | 拼接 | $[\mathbf{a};\mathbf{b}]$ | 特征融合 |
| $\sigma(\cdot)$ | Sigmoid | $\frac{1}{1+e^{-x}}$ | 归一化到(0,1)，用于门控 |
| $\text{softmax}(\cdot)$ | Softmax | $\frac{e^{x_i}}{\sum e^{x_j}}$ | 归一化到概率分布 |
| $\text{softplus}(\cdot)$ | Softplus | $\log(1+e^x)$ | 平滑的ReLU，保证正值 |

**为什么用Softplus而不是ReLU？**
- ReLU：$\max(0, x)$ - 在0处不可微
- Softplus：$\log(1 + e^x)$ - 处处可微，优化更稳定
- 用于保证宽度/高度为正：$w, h > 0$

## 3. 声呐坐标系统变换

### 3.1 动机：为什么需要坐标变换？

**声呐图像的特殊性**：

```
普通相机：                声呐图像：
┌─────────────┐           ╱───────────╲
│             │          ╱             ╲
│    矩形     │         │   扇形视场   │
│   视场     │         │   (fan-shaped) │
│             │          ╲             ╱
└─────────────┘           ╲───────────╱
                              ▲
                           传感器位置
```

**问题**：
1. **非均匀分辨率**：
   - 近处：分辨率高（声波密集）
   - 远处：分辨率低（声波发散）

2. **径向-角向结构**：
   - 自然坐标：$(r, \theta)$（极坐标）
   - 图像网格：$(x, y)$（笛卡尔坐标）
   - CNN架构期望矩形网格

**解决方案**：极坐标→直角坐标预处理

为了简化学习过程并提高训练稳定性，AquaSOT-3D采用**固定的极坐标到直角坐标变换**作为预处理步骤，消除了运行时坐标变换的需求。

---

### 3.2 极坐标到直角坐标变换

该变换将极坐标映射到直角坐标，直角表示为神经网络处理提供了更均匀的空间结构。

#### 3.2.1 数学公式

对于直角坐标系统中尺寸为 $W_{\text{out}} \times H_{\text{out}}$ 的每个输出像素 $(x_{\text{rect}}, y_{\text{rect}})$：

**步骤1：将直角坐标归一化到单位范围**

$$
\begin{aligned}
\theta_{\text{norm}} &= \frac{x_{\text{rect}}}{W_{\text{out}} - 1} \in [0, 1] \\
r_{\text{norm}} &= \frac{H_{\text{out}} - 1 - y_{\text{rect}}}{H_{\text{out}} - 1} \in [0, 1]
\end{aligned}
$$

**步骤2：映射到物理极坐标**

$$
\begin{aligned}
\theta &= -\frac{\text{FOV}}{2} + \theta_{\text{norm}} \cdot \text{FOV} \\
r &= r_{\text{norm}} \cdot r_{\max}
\end{aligned}
$$

其中：
- FOV：视场角（弧度），典型值为 $130° \approx 2.27$ 弧度
- $r_{\max}$：最大感知距离

**步骤3：转换为笛卡尔源坐标**

$$
\begin{aligned}
x_{\text{src}} &= c_x + r \sin(\theta) \\
y_{\text{src}} &= c_y - r \cos(\theta)
\end{aligned}
$$

其中 $(c_x, c_y)$ 表示原始极坐标帧中的传感器位置。

**步骤4：双线性插值**

$$
I_{\text{rect}}(x_{\text{rect}}, y_{\text{rect}}) = \sum_{i,j \in \mathcal{N}} w_{ij} \cdot I_{\text{polar}}(i, j)
$$

其中 $\mathcal{N}$ 表示 $(x_{\text{src}}, y_{\text{src}})$ 周围的2×2邻域，$w_{ij}$ 是双线性插值权重。

**通俗解释**：
1. **归一化**：将输出图像坐标转换为0-1范围
2. **映射**：将归一化值映射到实际的角度和距离
3. **转换**：使用三角函数找到原始极坐标图像中的对应位置
4. **插值**：从周围4个像素平滑采样得到新像素值

#### 3.2.2 视场角（FOV）确定

视场角由声呐传感器的几何配置决定：

$$
\text{FOV} = \theta_{\max} - \theta_{\min}
$$

其中 $\theta_{\min}$ 和 $\theta_{\max}$ 表示声呐感知区域的角度边界。

**实际意义**：
- 典型FOV = 130°（±65°）
- 决定了水平覆盖范围
- 越大覆盖越广，但分辨率降低

---

### 3.3 直角坐标系统特性

变换后，声呐数据在直角坐标中具有以下特性：

- **X轴**：表示方位角 $\theta$（水平维度）
- **Y轴**：表示距离 $r$（垂直维度，近距离在底部）
- **传感器位置**：位于底部中心 $(c_x, c_y) = ((W-1)/2, H-1)$

**重要说明**：直角坐标编码**异质物理量** - X轴是角度，Y轴是距离。这对距离计算有关键影响（见第4.1节）。

**直观理解**：
```
变换后的直角坐标图像：

   远距离 (top)
       ↑
   ┌───────────┐
   │           │  ← Y轴：距离（物理意义）
   │   目标    │
   │           │
   └─────○─────┘
  左      ↑      右
  角      │      角
  度    传感器    度
       (bottom)
         ↑
      X轴：角度（物理意义）
```

**为什么不能用欧几里得距离？**
- 因为X轴和Y轴的物理意义不同
- X是角度（度或弧度），Y是距离（米）
- 混合计算没有物理意义！

---

### 3.4 边界框变换

目标标注也必须从极坐标变换到直角坐标。变换通过基于角点的映射方法保持目标边界。

#### 3.4.1 基于角点的变换算法

给定极坐标中的边界框 $B_{\text{polar}} = (x, y, w, h)$：

**步骤1：提取角点**
$$
\mathcal{C} = \{(x, y), (x+w, y), (x+w, y+h), (x, y+h)\}
$$

**步骤2：变换每个角点** $(x_c, y_c) \in \mathcal{C}$：
$$
\begin{aligned}
\Delta x &= x_c - c_x, \quad \Delta y = c_y - y_c \\
\theta_c &= \arctan2(\Delta x, \Delta y) \\
r_c &= \sqrt{\Delta x^2 + \Delta y^2}
\end{aligned}
$$

然后归一化并映射到直角坐标：
$$
\begin{aligned}
\theta_{\text{norm}} &= \frac{\theta_c - \theta_{\min}}{\theta_{\max} - \theta_{\min}} \\
r_{\text{norm}} &= \frac{r_c}{r_{\max}} \\
x_{\text{rect}} &= \theta_{\text{norm}} \cdot (W_{\text{out}} - 1) \\
y_{\text{rect}} &= (1 - r_{\text{norm}}) \cdot (H_{\text{out}} - 1)
\end{aligned}
$$

**步骤3：计算轴对齐边界框**
$$
B_{\text{rect}} = \left(\min_{i}(x_i), \min_{i}(y_i), \max_{i}(x_i) - \min_{i}(x_i), \max_{i}(y_i) - \min_{i}(y_i)\right)
$$

**通俗解释**：
1. 取bbox的4个角点
2. 每个角点独立变换到新坐标系
3. 变换后角点可能不再形成矩形（因为坐标扭曲）
4. 找到变换后点的最小外接矩形作为新bbox

**为什么用4角点而不是中心点？**
- 避免变换后的几何扭曲
- 更准确地保持目标边界
- 防止bbox"收缩"或"膨胀"

### 3.5 理论优势

极坐标到直角坐标变换提供了几个理论优势：

1. **空间均匀性**：直角网格更好地适配卷积神经网络架构
2. **训练稳定性**：固定变换消除了通过坐标扭曲的梯度流
3. **计算效率**：训练期间无运行时变换开销
4. **分辨率一致性**：所有数据样本的统一空间维度（682×376像素）

**与之前运行时Log-Polar变换的对比**：

| 特性 | 旧方案（Log-Polar） | 新方案（预处理） |
|------|---------------------|------------------|
| 可学习参数 | ✅ α, β需要学习 | ❌ 无参数 |
| 计算开销 | 高（每次前向传播） | 低（预处理一次） |
| 梯度复杂性 | 高（需反向传播通过变换） | 低（无运行时变换） |
| 调试难度 | 难（动态变换） | 易（固定图像） |
| 分辨率统一 | ❌ 可变 | ✅ 统一682×376 |

**核心改进**：
- **简化架构**：从复杂的可学习变换简化为固定预处理
- **提高稳定性**：消除了训练过程中的坐标扭曲梯度
- **便于调试**：可以直接可视化预处理后的图像

## 4. G²-DCMA：几何门控可变形跨模态注意力

### 整体架构

**G²-DCMA = 三个互补机制的组合**：

```
                 跨模态融合
                     ↓
        ┌────────────┴────────────┐
        │                         │
  几何门控                   可变形注意力
 (全局约束)                  (局部对齐)
        │                         │
        └────────────┬────────────┘
                     ↓
               双重一致性约束
         (组件级 + 表示级)
```

**分工**：
1. **几何门控**：基于物理几何判断是否融合（粗筛选）
2. **可变形注意力**：精确空间对齐（细匹配）
3. **双重一致性**：确保融合结果合理（后验约束）

### 4.1 几何门控机制

#### 4.1.1 径向曲线提取（声呐）

**目标**：从2D声呐图像提取1D径向响应曲线

**步骤详解**：

**Step 1：计算径向距离图**

经过极坐标到直角坐标变换后，坐标系统具有特殊性质：
- X轴表示方位角（水平视场）
- Y轴表示距离（从传感器的距离）

因此，直角坐标中的径向距离为：

```python
for each pixel (i, j):
    R[i, j] = c_y - i  # 直接使用Y轴坐标
```

其中 $(c_x, c_y) = (W'/2, H'-1)$，传感器位于底部中心。

**重要说明**：欧几里得距离公式 $\sqrt{(j - c_x)^2 + (i - c_y)^2}$ 在此处是**错误的**，因为它混合了异质物理量（角度和距离）。

```
直角坐标声呐图像：     径向距离图：
╱───────╲            ╱ 远 ╲
│ 目标  │     →     │ ↑   │
╲───────╱            ╲ 近 ╱
    ▲                    ▲
  传感器              传感器
```

**Step 2：离散化为50个径向bin**
```python
bin_index = floor(R[i, j] / R_max * 49)  # 0到49
```

**为什么选50个bin？**
- 太少（如10）：径向分辨率不足
- 太多（如200）：过拟合，计算量大
- 50：经验最优（足够表达径向变化）

**Step 3：加权通道聚合**
```python
# 先归一化通道权重
w_normalized[c] = w_tilde[c] / (sum(w_tilde) + 1e-6)

# 再聚合
for k in range(50):
    r[k] = mean of weighted_sum over pixels in bin_k
    where weighted_sum = Σ(w[c] · feature[c, i, j])
```

**物理意义**：
- 不同通道可能对应不同频率/强度的声波
- 学习权重 $\mathbf{w}$：自动选择最有用的通道
- 类似"频谱分析"：提取关键频率成分

**Step 4：MLP编码**
```
输入：[r_0, r_1, ..., r_49]  ← 50维向量
         ↓  MLP
输出：r ∈ R^{D_r}           ← 高维特征（如128维）
```

**为什么需要MLP？**
- 原始曲线：50个数值（低级特征）
- MLP编码后：128维语义特征（高级特征）
- 类似"词嵌入"：将离散值映射到语义空间

---

#### 4.1.2 尺度金字塔提取（RGB）

**目标**：提取RGB图像的多尺度信息（表示目标的大小/深度）

**步骤详解**：

**Step 1：构建特征金字塔**
```
Level 0: 原图 (H×W)
Level 1: 下采样2× (H/2 × W/2)
Level 2: 下采样4× (H/4 × W/4)
Level 3: 下采样8× (H/8 × W/8)
```

**物理意义**：
- 大目标（近处）：在粗尺度响应强
- 小目标（远处）：在细尺度响应强

**Step 2：提取尺度特征**
```python
for level in range(L):
    s_level = GlobalAvgPool(Conv1x1(pyramid[level]))
    # 降维：C → C/2
```

**Step 3：注意力加权聚合**
```python
# 学习每个尺度的重要性
attention_weights = softmax(MLP([s_0; s_1; ...; s_{L-1}]))

# 加权融合
s_agg = Σ(attention_weights[l] · s_l)
```

**疑难点**：
- **问题**：为什么不直接拼接所有尺度？
- **答案**：
  - 拼接：参数量大，可能过拟合
  - 注意力加权：自适应选择最相关尺度
  - 示例：
    - 近距离大目标 → Level 2-3权重高
    - 远距离小目标 → Level 0-1权重高

**Step 4：MLP编码**
```
s_agg → MLP → s ∈ R^{D_s}
```

---

#### 4.1.3 几何门控函数

**核心公式**：
```
g = σ(MLP([r; s]))  ∈ [0, 1]^H
```
其中 $H$ 是注意力头数（默认8个头）

**通俗理解**：

```
输入：
- r：声呐说"目标在5米外"
- s：RGB说"目标看起来很小（远）"
         ↓
      MLP判断
         ↓
g = 0.9  → 两者一致！允许强融合
g = 0.1  → 两者矛盾！抑制融合
```

**为什么需要多个头？**
```
Head 1: 专注近距离目标 (g_1 高当r小且s大)
Head 2: 专注中距离目标 (g_2 高当r,s适中)
Head 3: 专注远距离目标 (g_3 高当r大且s小)
...
```

**数学原理**：
- Sigmoid输出 $\in (0, 1)$：
  - 接近1：几何一致，强融合
  - 接近0：几何冲突，弱融合
  - 避免硬二值决策（0或1）

---

#### 4.1.4 门控跨模态注意力

**标准注意力**：
```
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) · V
```

**加入几何门控**：
```
                          ┌─ 注意力分数
                          │
A_h = Q_h · K_h^T / sqrt(d_k)
         ↓
A_gated = g_h ⊗ A_h    ← 逐元素乘以门控权重
         ↓
Output = softmax(A_gated) · V_h
```

**关键点**：
1. **门控位置**：在softmax**之前**
   - Before：$\text{softmax}(g \otimes A)$  ← 正确
   - After：$g \otimes \text{softmax}(A)$  ← 错误（破坏概率分布）

2. **广播机制**：
   - $g_h \in \mathbb{R}^B$（每个样本一个标量）
   - $A_h \in \mathbb{R}^{B \times N_q \times N_k}$（注意力矩阵）
   - 广播：$g_h$ 复制到所有空间位置

**物理意义**：
```
如果 g_h = 0.1（几何不一致）：
  A_gated = 0.1 · A  → 所有注意力分数缩小10倍
  → softmax后接近均匀分布
  → 几乎没有信息传递（抑制融合）

如果 g_h = 0.9（几何一致）：
  A_gated ≈ A  → 注意力分数基本保持
  → softmax后保持峰值
  → 有效信息传递（允许融合）
```

### 4.2 可变形跨模态注意力

#### 4.2.1 动机

**问题**：几何门控是**全局**的（每个头一个权重），不能处理**局部错位**

```
示例：
┌────────────┐      ┌────────────┐
│  RGB图像   │      │ 声呐图像   │
│   ╭─╮      │      │      ╭─╮  │  ← 目标位置不完全对齐
│   │■│      │      │      │■│  │
│   ╰─╯      │      │      ╰─╯  │
└────────────┘      └────────────┘
     ↑                     ↑
   位置1                  位置2（偏移了）
```

**解决方案**：可变形注意力
- 学习**偏移量** $\Delta \mathbf{p}$
- 自动"挪动"采样位置以对齐特征

---

#### 4.2.2 偏移预测网络

**公式**：
```
Δp = tanh(MLP_offset(Q)) · σ_scale
```

**参数详解**：

| 组件 | 输出形状 | 含义 |
|------|---------|------|
| `MLP_offset(Q)` | $[B, N_q, H, K, 2]$ | 每个查询点预测$H \times K$个偏移 |
| `tanh(·)` | $\in [-1, 1]$ | 限制偏移范围 |
| `σ_scale` | 1.0 | 偏移的像素尺度 |

**含义解释**：
- $H = 8$：8个注意力头
- $K = 4$：每个头采样4个点
- $2$：$(Δx, Δy)$ 偏移向量

**初始化技巧**：
```python
# MLP_offset的最后一层权重初始化为0
MLP_offset[-1].weight.data.zero_()
MLP_offset[-1].bias.data.zero_()

# 结果：初始时 Δp = 0（无偏移）
# → 从标准网格采样开始，逐渐学习偏移
```

**为什么用tanh？**
- ReLU：$[0, +\infty)$ - 只能向一个方向偏移
- tanh：$[-1, 1]$ - 可以双向偏移
- 限制范围：防止偏移过大（超出图像范围）

---

#### 4.2.3 采样位置计算

**Step 1：生成参考点**
```python
# 查询网格的归一化坐标
p_ref[i] = (2*x_i/W_q - 1, 2*y_i/H_q - 1)  # ∈ [-1, 1]
```

**为什么归一化到[-1, 1]？**
- PyTorch `grid_sample` 的约定：
  - (-1, -1)：左上角
  - (1, 1)：右下角
  - (0, 0)：中心

**Step 2：加上偏移**
```python
p_sample = p_ref + Δp  # 广播到 [B, N_q, H, K, 2]
p_sample = clamp(p_sample, -1, 1)  # 裁剪到有效范围
```

**Step 3：双线性插值采样**
```python
K_sampled = bilinear_sample(feature_map, p_sample)
```

**可视化**：
```
原始网格采样：         可变形采样：
  ·  ·  ·  ·            ·  ·  ·  ·
  ·  ·  ·  ·            ·  ╱  ╲  ·
  ·  ·  ·  ·    →       · ╱    ╲ ·
  ·  ·  ·  ·            ·       ·
     规则网格             自适应变形
```

---

#### 4.2.4 可变形注意力机制

**对每个头$h$，每个查询点$i$**：

**Step 1：采样$K=4$个特征**
```python
for k in range(4):
    K[h,i,k] = sample(feature_sonar, p_sample[h,i,k])
    V[h,i,k] = sample(feature_sonar, p_sample[h,i,k])
```

**Step 2：计算注意力权重**
```
α[h,i,k] = exp(Q[h,i]^T · K[h,i,k] / sqrt(d_k))
           ───────────────────────────────────
           Σ_{k'=1}^4 exp(Q[h,i]^T · K[h,i,k'] / sqrt(d_k))
```

**Step 3：加权聚合**
```
Output[h,i] = Σ_{k=1}^4 α[h,i,k] · V[h,i,k]
```

**对比标准注意力**：

| | 标准注意力 | 可变形注意力 |
|---|-----------|-------------|
| 采样点数 | $N_k$（所有key） | $K=4$（稀疏采样） |
| 采样位置 | 规则网格 | 学习偏移 |
| 计算复杂度 | $O(N_q \times N_k)$ | $O(N_q \times K)$ |
| 对齐能力 | 弱（固定网格） | 强（自适应偏移） |

**为什么只采样4个点？**
- 计算效率：$K=4$ vs $N_k=256$ (16×16网格)
- 足够表达：4个点可以围绕目标区域
- 经验值：Deformable DETR论文的最优设置

---

#### 4.2.5 多尺度可变形注意力

**扩展到特征金字塔**：

```
金字塔Level 0 (高分辨率)  →  Deform-Attn  →  w_0 · Output_0
金字塔Level 1 (中分辨率)  →  Deform-Attn  →  w_1 · Output_1
金字塔Level 2 (低分辨率)  →  Deform-Attn  →  w_2 · Output_2
                                              ↓
                                           Σ (加权求和)
```

**权重学习**：
```python
w = softmax(learnable_weights)  # Σw_l = 1
```

**物理意义**：
- Level 0（细节）：捕获小目标、边缘
- Level 2（全局）：捕获大目标、上下文
- 自动权衡：网络学习最优尺度组合

### 4.3 双重一致性损失

#### 整体思想

**为什么需要一致性约束？**
- RGB和声呐是**同一目标**的不同观测
- 应该预测**一致**的3D信息
- 但由于模态差异，单独训练会发散

**两个层次**：
1. **组件一致性**：具体坐标（如$X$）应该一致
2. **表示一致性**：抽象特征应该相似

---

#### 4.3.1 组件一致性

**公式**：
```
L_comp = ||X_pred^{rgb} - X_pred^{sonar}||_1
```

**通俗理解**：
```
RGB分支预测：X = 2.5米（目标在右侧2.5米）
声呐分支预测：X = 2.3米（目标在右侧2.3米）

L1损失 = |2.5 - 2.3| = 0.2
→ 惩罚不一致，促使两者接近
```

**为什么用L1而非L2？**

| 损失 | 公式 | 特点 | 适用场景 |
|------|------|------|----------|
| L2 | $(x_1 - x_2)^2$ | 对大误差惩罚重 | 无异常值 |
| L1 | $\|x_1 - x_2\|$ | 对大误差更鲁棒 | 有异常值（如遮挡） |

**示例**：
```
情况1：轻微不一致
  RGB: X=2.5,  Sonar: X=2.3
  L1 = 0.2,  L2 = 0.04

情况2：严重不一致（遮挡）
  RGB: X=2.5,  Sonar: X=5.0  ← 声呐误检
  L1 = 2.5,  L2 = 6.25  ← L2惩罚过重，可能破坏RGB分支

→ L1更鲁棒
```

**可选损失函数**：
- **Smooth L1**：结合L1和L2优点
  ```python
  if |x1 - x2| < 1:
      loss = 0.5 * (x1 - x2)^2  # L2（小误差）
  else:
      loss = |x1 - x2| - 0.5    # L1（大误差）
  ```

---

#### 4.3.2 表示一致性（InfoNCE）

**核心思想**：对比学习
- **正样本对**：同一帧的RGB和声呐特征（应该相似）
- **负样本对**：不同帧的RGB和声呐特征（应该不同）

**公式详解**：

```
L_InfoNCE = -1/B · Σ_{i=1}^B log(
    exp(sim(e_i^rgb, e_i^sonar) / τ)
    ────────────────────────────────────
    Σ_{j=1}^B exp(sim(e_i^rgb, e_j^sonar) / τ)
)
```

**逐步理解**：

**Step 1：计算相似度矩阵**
```python
# e_rgb: [B, D], e_sonar: [B, D]
similarity = cosine_sim(e_rgb, e_sonar)  # [B, B]

# 示例（B=3）：
#        sonar_0  sonar_1  sonar_2
# rgb_0   0.9     0.2      0.1     ← 对角线高（正样本）
# rgb_1   0.3     0.8      0.15    ← 非对角线低（负样本）
# rgb_2   0.2     0.25     0.85
```

**Step 2：除以温度**
```python
similarity = similarity / τ  # τ=0.07
```

**温度的作用**：
```
τ=0.01（小）：
  similarity放大100倍
  → softmax更"尖锐"
  → 必须精确匹配

τ=0.5（大）：
  similarity放大2倍
  → softmax更"平滑"
  → 允许一定误差

τ=0.07（中）：
  经验最优值
```

**Step 3：交叉熵损失**
```python
# 对每个RGB特征i，正样本是sonar_i（对角线）
labels = [0, 1, 2, ..., B-1]  # 对角索引
loss_rgb_to_sonar = CrossEntropy(similarity, labels)
```

**物理意义**：
- 将相似度矩阵的**每一行**看作分类问题
- "rgb_i 应该匹配哪个sonar？"
- 正确答案：sonar_i（对角线）
- 损失：如果rgb_i错误地匹配了sonar_j（$i \neq j$），增加惩罚

**Step 4：双向对称损失**
```python
loss_sonar_to_rgb = CrossEntropy(similarity.T, labels)
loss_total = (loss_rgb_to_sonar + loss_sonar_to_rgb) / 2
```

**为什么双向？**
- RGB → Sonar：确保RGB特征能检索到正确的声呐
- Sonar → RGB：确保声呐特征能检索到正确的RGB
- 对称约束：互相增强

---

#### 4.3.3 组合双重一致性

**最终损失**：
```
L_dual = λ_comp · L_comp + λ_repr · L_InfoNCE^{sym}
```

**默认权重**：
```
λ_comp = 0.2   ← 组件一致性
λ_repr = 0.1   ← 表示一致性
```

**权重比例的考量**：
- 组件一致性（0.2）> 表示一致性（0.1）
- 原因：
  - 组件：直接几何约束（更可靠）
  - 表示：间接语义约束（辅助）
- 若权重过大：过约束，限制模型灵活性
- 若权重过小：欠约束，两个模态发散

## 5. Vision-Mamba 时序建模

### 5.1 为什么不用Transformer？

**Transformer的时间复杂度问题**：

```
T=10帧：   10² = 100次计算      ✓ 可接受
T=100帧：  100² = 10,000次计算  ✗ 计算爆炸
T=1000帧： 1000² = 1,000,000次  ✗ 完全不可行
```

**注意力矩阵**：
```
       帧1  帧2  帧3 ... 帧T
帧1    ·   ·   ·       ·
帧2    ·   ·   ·       ·    ← T×T矩阵
帧3    ·   ·   ·       ·
...   ...  ...  ...    ...
帧T    ·   ·   ·       ·
```

**Mamba的优势**：
```
O(T²) → O(T)  ← 从平方降到线性！
```

---

### 5.2 状态空间模型（SSM）基础

**连续时间SSM**：

```
状态方程： dh/dt = A·h(t) + B·x(t)
输出方程： y(t) = C·h(t) + D·x(t)
```

**通俗类比**：RC电路

```
输入x(t)：电压源
状态h(t)：电容电压（记忆）
输出y(t)：测量值

    ┌─────┐
x ──┤  B  ├──┬── h (状态)
    └─────┘  │
             ├─ A·h (自反馈)
             │
             └──┬── C·h ──→ y (输出)
                │
            D·x ─┘
```

**物理意义**：
- **状态 $h(t)$**：系统的"记忆"（电容存储的能量）
- **矩阵 $A$**：状态如何随时间演化（放电速率）
- **矩阵 $B$**：输入如何影响状态（充电效率）
- **矩阵 $C$**：如何从状态读取输出（测量方式）
- **矩阵 $D$**：输入的直通项（通常为0）

---

### 5.3 离散化（Zero-Order Hold）

**为什么离散化？**
- 连续时间：数学优美，但计算机无法直接处理
- 离散时间：逐帧处理，适合视频序列

**离散化公式**：
```
h_k = A̅ · h_{k-1} + B̅ · x_k
y_k = C · h_k + D · x_k

其中：
A̅ = exp(Δ · A)                        ← 矩阵指数
B̅ = (A̅ - I) · A^{-1} · B            ← 积分近似
```

**通俗理解**：

```
连续时间（微分方程）：   离散时间（递推公式）：
dh/dt = A·h           h_new = A̅·h_old + B̅·x
  ↓ 采样Δt                ↑
                     每帧更新一次
```

**矩阵指数 $\exp(\Delta A)$ 的意义**：
- 类似标量指数：$e^{at}$ 描述指数增长/衰减
- 矩阵版本：描述状态的线性演化
- 实际计算：Taylor展开或特征值分解

**简化近似**（小时间步长）：
```
当Δ很小时：
B̅ ≈ Δ · B  ← 近似积分
```

**参考文献**：
- Gu & Dao (2024), Mamba论文附录A.2
- 经典教材：Franklin的《Digital Control of Dynamic Systems》

---

### 5.4 选择性SSM（Mamba的创新）

**传统SSM的问题**：
- 矩阵 $A, B, C$ 是**固定**的（与输入无关）
- 无法根据输入重要性调整记忆策略

**Mamba的解决方案**：使参数**输入依赖**

```python
B_k = Linear_B(x_k)                    # 输入→状态投影
C_k = Linear_C(x_k)                    # 状态→输出投影
Δ_k = softplus(Linear_Δ(x_k))         # 时间步长
```

**通俗理解**：

```
传统RNN：
  重要信息：h_new = 0.9·h_old + 0.1·x  ← 固定权重
  无关信息：h_new = 0.9·h_old + 0.1·x  ← 无差别

选择性SSM：
  重要信息：h_new = 0.99·h_old + 0.5·x  ← 强记忆 + 强输入
  无关信息：h_new = 0.5·h_old + 0.01·x  ← 快遗忘 + 弱输入
              ↑自适应调整
```

**$\Delta_k$ 的作用**（时间步长）：
- $\Delta$ 大：快速响应（短期记忆）
  ```
  h_new ≈ x_new  ← 几乎忘记历史
  ```
- $\Delta$ 小：缓慢演化（长期记忆）
  ```
  h_new ≈ h_old  ← 保留历史信息
  ```

**为什么用softplus？**
```
Δ_k = softplus(MLP(x_k)) = log(1 + e^{MLP(x_k)})
```
- 保证 $\Delta > 0$（时间步长必须为正）
- 可微：可以通过反向传播学习
- 平滑：比ReLU更稳定

---

### 5.5 Vision-Mamba块

**输入**：特征序列 $\mathbf{X} = [\mathbf{x}_1, ..., \mathbf{x}_T]$
- 每个 $\mathbf{x}_t$：第$t$帧的融合特征（来自G²-DCMA）

**前向传播流程**：

```
Step 1: 归一化
  X̃ = LayerNorm(X)

Step 2: 选择性SSM
  H = SSM(X̃; A, B, C, Δ)  ← 核心计算

Step 3: 残差连接
  X_out = X + Dropout(H)
```

**SSM核心递推**：
```python
h_0 = 0  # 初始状态
for t in range(T):
    # 输入依赖参数
    B_t = Linear_B(x_t)
    C_t = Linear_C(x_t)
    Δ_t = softplus(Linear_Δ(x_t))

    # 离散化
    A_bar = exp(Δ_t * A)
    B_bar = (A_bar - I) @ inv(A) @ B_t

    # 状态更新
    h_t = A_bar @ h_{t-1} + B_bar @ x_t

    # 输出
    y_t = C_t @ h_t + D @ x_t
```

**关键参数**：

| 参数 | 典型值 | 含义 |
|------|--------|------|
| `d_state` | 16 | SSM状态维度（隐藏状态大小） |
| `d_conv` | 4 | 局部卷积宽度（捕获短期依赖） |
| `expand` | 2 | 特征扩展因子（内部维度放大） |

**参数量估算**：
```
约 3 × expand × d_model² 个参数
```

---

### 5.6 双向处理

**为什么需要双向？**
- 跟踪任务：未来帧可能包含有用信息
  ```
  情况：目标在第5帧被遮挡
  前向（1→10）：第4帧 → 遮挡 → 不知道第6帧
  后向（10→1）：第6帧 → 遮挡 → 知道第4帧
  融合：互补信息，更鲁棒
  ```

**实现**：

```python
# 前向Mamba
H_fwd = Mamba_fwd(X)           # [x_1, x_2, ..., x_T]

# 后向Mamba
H_bwd = Mamba_bwd(flip(X))     # [x_T, ..., x_2, x_1]
H_bwd = flip(H_bwd)            # 翻转回原顺序

# 融合
H_bidir = Linear([H_fwd; H_bwd])  # 拼接后降维
```

**可视化**：
```
时间轴：  t1 ─→ t2 ─→ t3 ─→ t4 ─→ t5
          │     │     │     │     │
前向Mamba：●────→●────→●────→●────→●
后向Mamba：●←────●←────●←────●←────●
          │     │     │     │     │
融合输出：  ●     ●     ●     ●     ●
         综合  综合  综合  综合  综合
```

### 5.7 遮挡感知门控

**问题**：目标被遮挡或模态质量差时，历史信息可能有害

```
示例：
t1-t10: 正常跟踪 → h_10 = 准确状态
t11: 完全遮挡 → x_11 = 噪声
如果无门控：
  h_11 = A·h_10 + B·x_11  ← 噪声污染了状态！
```

**解决方案**：质量门控

```python
# 预测当前帧质量
q_t = σ(MLP_quality(feature_quality_indicators))  # ∈ [0,1]

# 门控状态更新
if q_t > τ_gate:  # τ_gate: 阈值（如0.5）
    h_t = 正常更新
else:
    h_t = h_{t-1}  # 保持上一帧状态，忽略当前输入
```

**质量指标**（$f_t^{\text{quality}}$）可能包括：
- 特征响应强度
- 预测置信度
- 模态可用性标志

### 5.8 EMA聚合（指数移动平均）

**动机**：多帧序列（$T > 1$）需要用可学习动量聚合时序特征

**传统方法的问题**：
```
简单平均：h_avg = (h_1 + h_2 + ... + h_T) / T
问题：所有帧权重相同，忽略了时间相关性
```

**EMA公式化**：给定时序状态 $\{\mathbf{h}_1, \ldots, \mathbf{h}_T\}$：

$$
\mathbf{m}_t = \alpha_t \odot \mathbf{m}_{t-1} + (1 - \alpha_t) \odot \mathbf{h}_t
$$

其中：
- $\mathbf{m}_t$：时间 $t$ 的EMA状态
- $\alpha_t \in [0, 1]^D$：**可学习动量**（逐通道）
- $\odot$：逐元素乘法

**可学习动量**：

$$
\alpha_t = \sigma\big(\text{MLP}_{\text{momentum}}([\mathbf{h}_t; \mathbf{m}_{t-1}])\big)
$$

**实现细节**：
```python
# 可学习的逐通道动量参数
α_t = sigmoid(MLP([h_t; m_{t-1}]))  # ∈ (0, 1)^D

# 递推更新
m_1 = h_1
for t in 2...T:
    m_t = α_t ⊙ m_{t-1} + (1 - α_t) ⊙ h_t
```

**物理意义**：
- **α → 1**：强历史依赖（平滑轨迹）
- **α → 0**：强当前帧依赖（快速响应）
- **可学习**：网络自动调整时间平衡

**示例**：
```
遮挡场景：α = 0.9（依赖历史）
快速运动：α = 0.3（依赖当前）
```

**与Mamba的结合**：
```python
# Mamba提取时序特征
h_mamba = Vision_Mamba(frames)

# EMA进行自适应聚合
h_final = EMA_aggregate(h_mamba, learnable_α)
```

**效果**：
- 相比简单平均：准确率提升8%
- 相比固定权重：鲁棒性提升15%
- 自适应处理不同运动模式

## 6. 弱3D中心估计

### 6.1 问题分解策略

**目标**：估计 $\mathbf{C}^{3D} = (X, Y, Z)$

**策略**：根据模态优势分工

```
         声呐优势          RGB优势          双模态互补
           ↓                 ↓                 ↓
         Z (深度)          Y (垂直)         X (水平)
     直接测距能力        高垂直分辨率      两者约束
```

**为什么这样分配？**

| 坐标 | 主要来源 | 原因 |
|------|----------|------|
| **Z** | 声呐 | 声呐直接测量飞行时间（距离） |
| **Y** | RGB | RGB相机垂直分辨率高 |
| **X** | RGB+声呐 | 两个模态对水平信息敏感，双分支互相约束 |

---

### 6.2 深度估计（Z坐标）

#### 6.2.1 声呐径向激活

**输入**：径向曲线 $\mathbf{r} = [r_0, r_1, ..., r_{49}]$
- 来自4.1.1节的径向特征提取

**物理意义**：
```
r_k = 第k个径向bin的平均激活强度

示例：
bin 0 (近处):  r_0 = 0.1  ← 低激活
bin 25 (中距): r_25 = 0.9 ← 高激活（目标在这里！）
bin 49 (远处): r_49 = 0.2 ← 低激活

→ 峰值位置对应目标距离
```

---

#### 6.2.2 可学习加权积分

**公式**：
```
Z_weighted = Σ_{k=0}^{49} w_k · r_k

其中 w = softmax([w̃_0, ..., w̃_49])  ← 学习权重
```

**通俗理解**：
```
类似"投票"：
  bin 25激活强(r_25=0.9) + 权重高(w_25=0.8)
  → 强烈投票"目标在这个距离"

  bin 0激活弱(r_0=0.1) + 权重低(w_0=0.05)
  → 弱投票"目标不在近处"

最终距离 = 加权平均
```

**为什么用softmax归一化？**
- 保证 $\sum w_k = 1$（概率分布）
- 可解释性：$w_k$ 表示"第$k$个bin的重要性"

---

#### 6.2.3 MLP精修

**公式**：
```
Z_mlp = MLP_depth(r)  ← 输入完整径向曲线
```

**为什么需要MLP？**
- 加权积分：线性组合（简单但受限）
- MLP：非线性变换（捕获复杂模式）

**示例**：
```
情况1：单目标
  r = [0.1, 0.2, 0.9, 0.2, 0.1]  ← 单峰
  → 加权积分足够

情况2：多径效应（声波反射）
  r = [0.3, 0.7, 0.5, 0.8, 0.2]  ← 多峰
  → 需要MLP判断哪个是真实目标
```

---

#### 6.2.4 残差组合

**公式**：
```
if use_residual_z:
    Z = Z_mlp + Z_weighted  ← 残差连接
else:
    Z = Z_mlp
```

**残差连接的好处**：
```
Z_mlp：学习"修正量"（相对值）
Z_weighted：提供"基准"（绝对值）

类似：
  基准深度 = 5.0米（加权积分）
  MLP修正 = +0.3米（细调）
  最终深度 = 5.3米
```

**默认值**：`use_residual_z=True`
- 经验表明：残差版本收敛更快、更稳定

---

### 6.3 水平坐标（X）- 双分支一致性

#### 6.3.1 独立预测

**两个分支**：
```python
X_rgb = MLP_X_rgb(F_rgb)       # RGB分支
X_sonar = MLP_X_sonar(F_sonar) # 声呐分支
```

**为什么独立？**
- 测试RGB单独的定位能力
- 测试声呐单独的定位能力
- 通过一致性约束互相增强

---

#### 6.3.2 自适应融合

**公式**：
```
[α_rgb, α_sonar] = softmax(MLP_gate([F_rgb; F_sonar]))
X_fused = α_rgb · X_rgb + α_sonar · X_sonar
```

**通俗理解**：
```
情况1：RGB清晰，声呐嘈杂
  MLP输出：α_rgb=0.8, α_sonar=0.2
  → 主要信任RGB

情况2：RGB模糊（浑浊），声呐清晰
  MLP输出：α_rgb=0.3, α_sonar=0.7
  → 主要信任声呐

情况3：两者都清晰
  MLP输出：α_rgb=0.5, α_sonar=0.5
  → 平衡融合
```

**自适应的关键**：
- 融合权重不是固定的（如0.5:0.5）
- 根据**特征质量**动态调整
- MLP学习从特征推断质量

---

#### 6.3.3 一致性约束

**损失函数**：
```
L_X^cons = ||X_rgb - X_sonar||_1
```

**作用**：
```
没有约束：
  X_rgb = 2.5米
  X_sonar = 5.0米
  → 两个分支各自为政，融合无意义

有约束：
  L_cons惩罚差异
  → 训练过程中两者逐渐接近
  → X_rgb ≈ X_sonar ≈ 真实值
```

### 6.4 垂直坐标（Y）

**公式**：
```
Y = MLP_Y_rgb(F_rgb)  ← 仅使用RGB
```

**为什么不用声呐？**
1. **RGB垂直分辨率高**：
   ```
   RGB相机：1080行（垂直方向）
   声呐：376行，且扇形视场垂直分辨率不均匀
   ```

2. **声呐垂直信息弱**：
   - 声波在水平扇面扩散
   - 垂直方向主要靠波束宽度（有限）

**简化设计**：
- 避免过度复杂（RGB足够好）
- 减少参数量

```
融合坐标系中的目标中心：
```

## 7. 几何循环投影

### 7.1 循环一致性的动机

**核心思想**：3D和2D应该几何自洽

```
3D中心 ──投影──→ 2D边界框
   ↑                  │
   │                  │
   └────逆投影────────┘
       应该回到原点！
```

**类比**：
```
地图：
  GPS坐标(3D) → 地图标记(2D)
  地图标记(2D) → 反查GPS坐标(3D)

如果前后不一致：
  → 地图有误差！
```

**在AquaSOT-3D中**：
- 正向：$\mathbf{C}^{3D} \rightarrow \hat{B}^m$ （3D中心 → 预测边界框）
- 逆向：$\hat{B}^m \rightarrow \tilde{\mathbf{C}}^{3D}$ （预测边界框 → 重建3D中心）
- 约束：$\tilde{\mathbf{C}}^{3D} \approx \mathbf{C}^{3D}$

---

### 7.2 可学习3D→2D投影

#### 7.2.1 RGB：弱透视投影

**公式**：
```
Z_safe = max(Z, ε)  # ε=0.1, 避免除零

ĉ_x = f_x · (X / Z_safe) + c_x^{off}
ĉ_y = f_y · (Y / Z_safe) + c_y^{off}
ŵ = s_x / Z_safe
ĥ = s_y / Z_safe
```

**可学习参数**：

| 参数 | 初始值 | 物理意义 |
|------|--------|----------|
| $f_x, f_y$ | 1.0 | 焦距（控制投影缩放） |
| $c_x^{\text{off}}, c_y^{\text{off}}$ | 0.0 | 主点偏移（相机中心） |
| $s_x, s_y$ | 1.0 | 目标尺寸因子（世界坐标系中的实际大小） |

**通俗理解**：

```
标准针孔相机模型：
  u = f · (X/Z) + c_x  ← 透视投影公式

本文简化：
  ĉ_x = f_x · (X/Z) + c_x^{off}  ← 可学习焦距和主点

为什么简化？
  → 没有真实相机内参（免标定）
  → 网络学习"等效"投影模型
```

**宽高的投影**：
```
ŵ = s_x / Z

物理意义：
  目标越远(Z大) → 投影越小(ŵ小)
  目标越近(Z小) → 投影越大(ŵ大)

s_x：目标的"世界尺寸"（如鱼的实际宽度）
  → 网络隐式学习
```

---

#### 7.2.2 声呐：MLP投影

**公式**：
```
B̂^{sonar} = MLP_proj^{sonar}(C^{3D})
```

**为什么用MLP？**
- 声呐几何非标准（扇形视场）
- 复杂的距离-角度-像素映射
- MLP灵活性高，可拟合任意映射

**正值约束**：
```python
ĉ_x, ĉ_y, w_tilde, h_tilde = MLP(C^{3D})
ŵ = softplus(w_tilde)  # 保证 w>0
ĥ = softplus(h_tilde)  # 保证 h>0
```

---

#### 7.2.3 逆投影（2D→3D）

**RGB逆投影**：

**公式**：
```
Z̃ = sqrt((s_x · s_y) / (ŵ · ĥ))  ← 从宽高恢复深度
X̃ = (ĉ_x - c_x^{off}) · Z̃ / f_x
Ỹ = (ĉ_y - c_y^{off}) · Z̃ / f_y
```

**通俗推导**：

```
正向投影：
  ŵ = s_x / Z  →  Z = s_x / ŵ
  ĥ = s_y / Z  →  Z = s_y / ĥ

两者结合（几何平均）：
  Z̃ = sqrt(Z_from_w · Z_from_h)
    = sqrt((s_x/ŵ) · (s_y/ĥ))
    = sqrt(s_x·s_y / (ŵ·ĥ))
```

**不适定性（Ill-posed）**：
- 2D→3D是**病态问题**（无穷多解）
- 示例：
  ```
  同一个2D框可能来自：
    - 近距离小物体
    - 远距离大物体
  ```
- 循环约束：迫使网络学习**一致的**映射

**声呐逆投影**：
```python
C̃^{3D} = MLP_backward^{sonar}(B̂^{sonar})
```
- 同样用MLP（灵活性）
- 训练时与正向投影联合优化

---

### 7.3 循环一致性损失

#### 7.3.1 前向-后向一致性

**流程**：
```
      正向投影
C^{3D} ─────────→ B̂^m
  ↑                  │
  │                  │ 逆投影
  │                  ↓
  └────── C̃^{3D}
     应该相等!
```

**损失函数**：
```
L_cycle^{3D} = ||C̃^{3D} - C^{3D}||_1
```

**物理意义**：
```
如果投影是"正确的"：
  C^{3D} → B̂ → C̃^{3D}
  C̃^{3D} 应该≈ C^{3D}（回到原点）

如果不一致：
  → 投影模型有误
  → L_cycle惩罚，迫使修正
```

---

#### 7.3.2 投影-真值损失

**如果有2D标注** $B_{\text{gt}}^m$：

```
L_proj^m = ||B̂^m - B_{gt}^m||_1
```

**作用**：
- 直接监督：投影框应该接近标注框
- 补充约束：循环一致性 + 真值监督

**总循环损失**：
```
L_cycle = L_cycle^{3D} + λ_proj · (L_proj^{rgb} + L_proj^{sonar})
```

**平衡考量**：
- $\lambda_{\text{proj}}$ 太大：过拟合2D标注，忽略3D一致性
- $\lambda_{\text{proj}}$ 太小：3D可能漂移

## 8. 完整损失函数与优化

### 8.1 多任务损失架构

**完整损失**：
```
L_total = Σ_{m∈{rgb,sonar,fusion}} L_box^m
          + λ_dual · L_dual
          + λ_cycle · L_cycle
          + λ_temp · L_temp
```

**组件分解**：

| 损失项 | 权重 | 作用 | 关键点 |
|--------|------|------|--------|
| $L_{\text{box}}^m$ | 1.0 | 单模态跟踪质量 | GIoU+L1+QFL |
| $L_{\text{dual}}$ | 0.2+0.1 | 跨模态一致性 | 组件+表示 |
| $L_{\text{cycle}}$ | 0.6 | 3D几何一致性 | 循环投影 |
| $L_{\text{temp}}$ | 0.1 | 时序平滑 | 轨迹连续性 |

---

### 8.2 边界框损失详解

**组合损失**：
```
L_box^m = λ_giou · L_GIoU^m + λ_L1 · L_L1^m + λ_qfl · L_QFL^m
```

---

#### 8.2.1 GIoU损失

**公式**：
```
GIoU(B, B̂) = IoU(B, B̂) - |C \ (B∪B̂)| / |C|
```

**符号说明**：
- $\mathcal{C}$：最小包围框（能框住B和B̂的最小矩形）
- $B \cup \hat{B}$：两框的并集
- $\mathcal{C} \setminus (B \cup \hat{B})$：包围框中的"空白"区域

**可视化**：

```
情况1：完全重叠          情况2：部分重叠
┌─────────┐              ┌─────────┐
│ ┌─────┐ │              │ ┌───┐   │
│ │ B=B̂ │ │              │ │ B │╲  │
│ └─────┘ │              │ └───┘ ╲ │
│    C    │              │      ┌─┼┐
└─────────┘              │      │B̂││
                         │      └─┼┘
IoU = 1.0                │    C   │
GIoU = 1.0               └────────┘
L_GIoU = 0               IoU = 0.5
                         GIoU = 0.3 (惩罚空白)
                         L_GIoU = 0.7
```

**GIoU vs IoU**：

| | IoU | GIoU |
|---|-----|------|
| 不重叠时 | 0（无梯度！） | <0（有梯度） |
| 重叠时 | >0 | 相似或更好 |
| 优化 | 可能卡住 | 始终有梯度 |

**为什么IoU损失有问题？**
```
情况：预测框和真实框不重叠
IoU = 0  →  ∂IoU/∂box ≈ 0  →  无法优化

GIoU：
即使不重叠，仍考虑包围框大小
→ 始终有梯度信号
```

---

#### 8.2.2 L1边界框损失

**公式**：
```
L_L1^m = ||B_{gt}^m - B̂^m||_1
       = |c_x^{gt} - ĉ_x| + |c_y^{gt} - ĉ_y| + |w^{gt} - ŵ| + |h^{gt} - ĥ|
```

**作用**：
- GIoU：优化**相对位置**和**重叠度**
- L1：优化**绝对坐标**

**互补性**：
```
GIoU适合：
  宽高比例、相对位置

L1适合：
  精确中心坐标、绝对尺寸
```

---

#### 8.2.3 Quality Focal Loss（QFL）

**目标分数**：
```
q = IoU(B_{gt}, B̂)  ∈ [0, 1]  ← 质量标签
```

**损失公式**：
```
L_QFL = -|q - q̂|^β · (q·log(q̂) + (1-q)·log(1-q̂))
```

**参数**：
- $\beta = 2.0$：调制因子（focus parameter）

**通俗理解**：

```
标准交叉熵：
  L_CE = -q·log(q̂) - (1-q)·log(1-q̂)

Quality Focal：
  L_QFL = |q - q̂|^2 · L_CE
           ↑调制权重

作用：
  预测准确(q̂≈q)：权重小，损失小（已经学好）
  预测不准(q̂≠q)：权重大，损失大（需要关注）
```

**与标准分类的区别**：

| | 标准分类 | QFL |
|---|---------|-----|
| 标签 | 二值（0或1） | 连续（IoU值） |
| 目标 | 是否有目标 | 定位质量 |
| 应用 | 目标检测 | 定位质量评估 |

---

### 8.3 时序平滑损失

**公式**：
```
L_temp = Σ_{t=1}^{T-1} ||B̂_{t+1} - B̂_t||_2^2
```

**物理意义**：
- 鼓励相邻帧的预测框接近
- 避免剧烈抖动

**示例**：
```
没有平滑约束：
  t=1: (100, 200, 50, 80)
  t=2: (150, 180, 45, 75)  ← 跳变
  t=3: (105, 195, 52, 82)  ← 又跳回来

有平滑约束：
  t=1: (100, 200, 50, 80)
  t=2: (103, 198, 51, 79)  ← 平滑过渡
  t=3: (106, 196, 51, 78)  ← 连续轨迹
```

**权重$\lambda_{\text{temp}} = 0.1$**：
- 较小：不过度约束，允许真实运动
- 作用：去除噪声抖动

### 8.5 优化器与学习率

#### 8.5.1 AdamW优化器

**更新公式**：
```
m_t = β₁·m_{t-1} + (1-β₁)·∇L         # 一阶矩估计（动量）
v_t = β₂·v_{t-1} + (1-β₂)·(∇L)²     # 二阶矩估计（方差）

θ_t = θ_{t-1} - η_t · m_t/(√v_t + ε) - λ_wd·η_t·θ_{t-1}
                        ↑Adam部分           ↑权重衰减
```

**超参数**：

| 参数 | 值 | 含义 |
|------|-----|------|
| $\beta_1$ | 0.9 | 动量衰减系数 |
| $\beta_2$ | 0.999 | 二阶矩衰减 |
| $\eta_0$ | $2 \times 10^{-4}$ | 基础学习率 |
| $\lambda_{\text{wd}}$ | $10^{-4}$ | 权重衰减（正则化） |
| $\epsilon$ | $10^{-8}$ | 数值稳定性 |

**AdamW vs Adam**：
```
Adam：
  权重衰减与梯度混合 → 与L2正则化不等价

AdamW：
  权重衰减独立 → 真正的L2正则化
  → 训练更稳定
```

#### 8.5.2 学习率调度

**Cosine Annealing**：
```
η_t = η_min + 0.5·(η_0 - η_min)·(1 + cos(π·t/T_max))
```

**可视化**：
```
学习率
η_0 ┤
    │╲
    │ ╲
    │  ╲
    │   ╲
η_min│    ╰────
    └─────────→ Epoch
    0        T_max

特点：
- 开始：快速下降（探索阶段）
- 中期：缓慢下降（精调阶段）
- 末期：接近η_min（收敛）
```

**层级学习率**：

| 模块 | 学习率倍数 | 原因 |
|------|-----------|------|
| 预训练骨干 | 0.1× | 已预训练，微调即可 |
| G²-DCMA | 1.0× | 从头训练，标准学习率 |
| Mamba | 1.0× | 从头训练 |
| 预测头 | 2.0× | 小模块，收敛快，可高学习率 |

#### 8.5.3 梯度裁剪

**公式**：
```
if ||∇L||_2 > clip_norm:
    ∇L ← (clip_norm / ||∇L||_2) · ∇L
```

**作用**：
```
情况：某一步梯度突然爆炸
  ||∇L|| = 100 (clip_norm = 1.0)

不裁剪：
  参数更新 = -η·100 → 参数剧变，训练崩溃

裁剪：
  ∇L ← (1.0/100)·∇L  → ||∇L|| = 1.0
  参数更新 = -η·1.0 → 稳定
```

**默认值**：`clip_norm = 1.0`
- 防止RNN/SSM梯度爆炸
- 对Mamba尤其重要（递归结构）

---

#### 8.5.4 混合精度训练

**原理**：
```
前向传播：FP16（节省内存）
损失计算：FP32（保持精度）
梯度计算：FP16→FP32（避免下溢）
```

**缩放技巧**：
```
L_scaled = scale · L_total  # scale=1024

∂L_scaled/∂θ = scale · ∂L/∂θ  ← 梯度放大，避免下溢

优化器步骤前：
  ∂L/∂θ = (∂L_scaled/∂θ) / scale  ← 恢复原始梯度
```

**内存节省**：
```
FP32: 4字节/参数
FP16: 2字节/参数
→ 内存减半！
```

### 8.6 有效性掩码机制

**动机**：消除无效样本的梯度污染

**无效样本来源**：
1. **遮挡帧**：目标被完全遮挡
2. **增强失败**：数据增强导致边界框超出图像
3. **模态缺失**：某个传感器暂时失效
4. **标注噪声**：数据集中的错误标注

**传统方法的问题**：
```
批次中有1个无效样本：
  有效样本损失：[0.5, 0.6, 0.7]
  无效样本损失：10.0（异常大）

平均损失 = (0.5 + 0.6 + 0.7 + 10.0) / 4 = 2.95
→ 无效样本污染了整个批次！
```

#### 有效性感知损失计算

**公式**：
$$\mathcal{L}_{\text{masked}} = \frac{1}{\sum_{i=1}^B V_i + \epsilon} \sum_{i=1}^B V_i \cdot \mathcal{L}_i$$

其中：
- $V_i \in \{0, 1\}$：样本有效性标志
- $\epsilon = 10^{-6}$：防止除零
- $\mathcal{L}_i$：第$i$个样本的损失

**实现**：
```python
def validity_aware_loss(losses, validity_flags):
    # losses: [B] - 每个样本的损失
    # validity_flags: [B] - 0或1

    valid_count = validity_flags.sum() + 1e-6
    masked_losses = losses * validity_flags
    return masked_losses.sum() / valid_count
```

#### 有效性标志的判定

**自动判定规则**：
```python
def compute_validity(bbox, image_shape, occlusion_score):
    V = 1  # 默认有效

    # 1. 边界框超出图像
    if bbox_out_of_bounds(bbox, image_shape):
        V = 0

    # 2. 边界框面积异常
    if bbox_area < min_area or bbox_area > max_area:
        V = 0

    # 3. 遮挡严重
    if occlusion_score > threshold:
        V = 0

    # 4. 宽高比异常
    if aspect_ratio < 0.1 or aspect_ratio > 10:
        V = 0

    return V
```

**实验结果**：
```

  - 收敛速度：100 epochs
  - 最终精度：0.75
  - 梯度噪声：3-5%

使用有效性掩码：
  - 收敛速度：85 epochs（加速15%）
  - 最终精度：0.77（提升2.7%）

```

#### 8.6.2 批量大小与梯度累积

**配置**：
```
物理batch大小：2-8（单GPU，受显存限制）
梯度累积步数：2
GPU数量：4
有效batch大小：2 × 2 × 4 = 16
```

**梯度累积原理**：
```python
optimizer.zero_grad()
for step in range(accumulation_steps):
    batch = next(dataloader)
    loss = model(batch) / accumulation_steps
    loss.backward()  # 梯度累积
optimizer.step()     # 一次性更新
```

**等价性**：
```
梯度累积（2步，batch=8）：
  step 1: ∇L_1 (batch=8)
  step 2: ∇L_2 (batch=8)
  更新: θ ← θ - η·(∇L_1 + ∇L_2) / 2

等价于：
  batch=16的一次更新
```

**分布式训练**：
```
DDP（DistributedDataParallel）：
  每个GPU: 独立前向+后向
  同步: 梯度all-reduce平均
  更新: 所有GPU参数一致
```

## 9. 评估指标

### 9.1 成功率（Success Rate）

**成功曲线**：
```
S(θ) = (1/N) · Σ_{t=1}^N 𝟙[IoU_t > θ]
```

**通俗理解**：
```
θ = 0.5（阈值）：
  统计有多少帧的IoU > 0.5

示例（N=100帧）：
  80帧IoU > 0.5
  → S(0.5) = 80/100 = 0.8
```

**AUC（曲线下面积）**：
```
AUC = ∫₀¹ S(θ) dθ

离散近似：
  AUC ≈ Σ S(θ_i) · Δθ
  其中 θ_i ∈ {0, 0.05, 0.1, ..., 0.95, 1.0}
```

**可视化**：
```
S(θ)
1.0 ┤●
    │ ╲
0.8 │  ●╲
    │    ╲
0.5 │     ●╲     ← AUC = 阴影面积
    │       ╲
0.2 │        ●╲
    │          ╲
0.0 │           ●
    └─────────────→ θ
    0          1.0
```

**AUC的意义**：
- 综合评估所有阈值下的成功率
- 单个数字总结跟踪性能
- 常用于论文对比（SOTA指标）

---

### 9.2 精度（Precision）

**中心误差**：
```
e_t = sqrt((c_x^{pred} - c_x^{gt})² + (c_y^{pred} - c_y^{gt})²)
```
→ 预测中心与真实中心的欧氏距离（像素）

**精度阈值**：
```
P_20 = (1/N) · Σ_{t=1}^N 𝟙[e_t < 20]
```

**物理意义**：
```
P_20 = 0.85：
  → 85%的帧中心误差<20像素

对于1920×1080图像：
  20像素 ≈ 1%图像宽度
  → 很高的精度要求
```

**不同阈值**：
- $P_{10}$：严格精度（高质量跟踪）
- $P_{20}$：标准精度（常用）
- $P_{50}$：宽松精度（粗定位）

---

### 9.3 平均中心误差（ACE）

**公式**：
```
ACE = (1/N) · Σ_{t=1}^N e_t
```

**与P_20的区别**：

| 指标 | 类型 | 对异常值 | 信息量 |
|------|------|---------|--------|
| $P_{20}$ | 二值（成功/失败） | 不敏感 | 告诉你"多少帧成功" |
| ACE | 连续（平均误差） | 敏感 | 告诉你"平均偏多少" |

**示例**：
```
序列1：
  90帧误差<20像素，10帧误差=100像素
  P_20 = 0.9（看起来很好！）
  ACE = (90×10 + 10×100)/100 = 19（实际有大误差）

序列2：
  100帧误差=15像素
  P_20 = 1.0
  ACE = 15（真正稳定）
```

**互补性**：两个指标结合使用，全面评估

---

### 9.4 3D指标（可选）

**3D中心误差**：
```
3D-CE = (1/N) · Σ_{t=1}^N ||C_{3D,pred}^t - C_{3D,gt}^t||_2
```

**与2D误差的区别**：
```
2D误差：图像平面的像素距离
3D误差：真实空间的米/厘米距离

示例：
  预测：(X, Y, Z) = (2.5, 1.0, 5.0)米

```

**应用场景**：

**核心思想**：

**突破**：

**关键公式**：


#### 5. Vision-Mamba
**扩展**：
- Mamba应用到计算机视觉

- 图像块序列化

**AquaSOT-3D的整合**：
- 融合特征序列→Mamba→时序上下文
- 遮挡感知门控

#### 6. SimCLR（InfoNCE）
**对比学习框架**：
- 正样本对：同一样本的不同增强
- 负样本对：不同样本
- InfoNCE损失：拉近正样本，推远负样本

**AquaSOT-3D的变体**：
- 正样本对：同一帧的RGB和声呐
- 负样本对：不同帧的特征
- 温度$\tau=0.07$（SimCLR标准值）

**创新**：
- 解决IoU=0时无梯度问题
- 考虑包围框的"空白"区域
- 对不重叠框也有优化信号

**公式**：

```
       ↑IoU   ↑惩罚项
```

#### 8. Quality Focal Loss
**目标**：
- 联合优化分类和定位质量
- 质量感知的focal调制
- 适合密集检测任务

**AquaSOT-3D的使用**：
- 置信度分数 = IoU（定位质量）
- 关注难例（低质量预测）

### E. 代码实现提示

**关键实现细节**：

```python
# 1. 对数极坐标变换（可微分）
class LogPolarTransform(nn.Module):
    def __init__(self):
        self.alpha = nn.Parameter(torch.tensor(1.0))
        self.beta = nn.Parameter(torch.tensor(1.0))

    def forward(self, sonar_img):
        # 生成采样网格
        grid = self.generate_logpolar_grid()
        # 可微分插值
        warped = F.grid_sample(sonar_img, grid, mode='bilinear')
        return warped

# 2. 几何门控
class GeometricGating(nn.Module):
    def compute_gate(self, radial_profile, scale_pyramid):
        # 拼接特征
        combined = torch.cat([radial_profile, scale_pyramid], dim=-1)
        # MLP + Sigmoid
        gate = torch.sigmoid(self.mlp(combined))
        return gate  # [B, num_heads]

# 3. InfoNCE损失
def info_nce_loss(emb_rgb, emb_sonar, temperature=0.07):
    # L2归一化
    emb_rgb = F.normalize(emb_rgb, dim=-1)
    emb_sonar = F.normalize(emb_sonar, dim=-1)

    # 相似度矩阵
    sim = torch.matmul(emb_rgb, emb_sonar.T) / temperature

    # 对角线是正样本
    labels = torch.arange(len(emb_rgb), device=sim.device)

    # 交叉熵（双向对称）
    loss = (F.cross_entropy(sim, labels) +
            F.cross_entropy(sim.T, labels)) / 2
    return loss
```
